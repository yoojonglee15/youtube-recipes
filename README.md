# 🍳 나만의 유튜브 레시피북 (101선)

유튜브 **'레시피'** 재생목록의 요리·베이킹 영상 101개를 한눈에 검색하고 조리 순서·재료·타이머와 함께 관리할 수 있는 웹 애플리케이션입니다.

## ✨ 주요 기능
- **101개 레시피 전체 수록**: 한식(26), 양식(25), 일식(13), 베이킹(12), 디저트(8), 반찬(6), 국·찌개(6), 중식(3), 기타(2)
- **실시간 통합 검색 & 카테고리 필터**: 요리 제목, 재료명(예: `삼겹살`, `파스타`, `두부`), 유튜브 채널명으로 즉시 검색 및 즐겨찾기(`★`) 관리
- **유튜브 영상 연동 & 타임스탬프 이동**: 조리 단계별 시간 버튼(예: `▶ 0:33 장면 보기`) 클릭 시 해당 조리 장면으로 바로 이동
- **재료 체크리스트 & 멀티 주방 타이머**: 그룹별(`주재료`, `양념장`, `소스`) 재료 준비 체크 및 단계별 카운트다운 알림 타이머 지원
- **레시피 추가·수정·삭제 & 백업 관리**: 브라우저 `localStorage` 자동 저장 및 `recipes-backup.json` 내보내기/불러오기 지원

## 📂 파일 구성
- `index.html` — 101개 레시피 데이터가 기본 내장된 단일 페이지 웹앱 (별도 서버 없이 바로 열기 가능)
- `recipes-backup.json` — 전수 검수 및 보완된 101개 레시피 원본 JSON 데이터
